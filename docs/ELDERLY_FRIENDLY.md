# 어르신 친화적 설명 가이드

## 변경 사항

### 1. 쉬운 언어 사용

**변경 전:**
"The Part B late enrollment penalty is generally calculated as 10% of the standard premium for each 12-month period you were eligible but didn't enroll."

**변경 후:**
"핸드북에 따르면, Part B에 늦게 가입하시면 늦은 해마다 10%씩 더 내셔야 합니다."

### 2. 출처 명확히 표시

이제 답변에서 정보의 출처를 명확히 구분합니다:

**메뉴얼 정보:**
- "메디케어 핸드북에 따르면 [27페이지]..."
- "According to the Medicare Handbook [Page 27]..."

**일반 지식:**
- "예를 들어 (핸드북에는 없는 일반 정보)..."
- "For example (general information, not in handbook)..."

### 3. 메뉴얼 우선 + 일반 지식 보완

- **우선**: 메뉴얼에 있는 정보 사용
- **보완**: 메뉴얼에 없으면 일반 Medicare 지식 활용
- **명시**: 어느 출처인지 항상 표시

### 4. 친근한 UI 메시지

**이전:**
"Disclaimer: This information is for general guidance only. Please consult official Medicare resources or a qualified professional for specific advice."

**변경:**
"💡 참고하세요: 이 정보는 도움을 드리기 위한 안내입니다. 중요한 결정을 하실 때는 Medicare 공식 기관(1-800-MEDICARE)이나 전문가와 상담하시는 것이 좋습니다."

## 프롬프트 주요 변경

### 1. 대상 명시
"You are a friendly Medicare expert helping elderly people (60+)"

### 2. 쉬운 언어 지시
- "Use simple, clear language"
- "Avoid jargon and complex terms"
- "Use short sentences"
- "Explain like talking to a family member"

### 3. 유연한 지식 활용
- "If information IS in the manual: Use it and cite clearly"
- "If information is NOT in the manual: Use your general knowledge and state it's not from the manual"
- "Always try to be helpful"

### 4. 출처 구분
- 메뉴얼: "According to the Medicare Handbook [Page X]..."
- 일반 지식: "Based on general Medicare information (not in your handbook)..."

## 예시

### 질문: "Part B에 늦게 가입하면 어떻게 되나요?"

**답변 형식:**
```
메디케어 핸드북에 따르면 [27페이지], Part B에 늦게 가입하시면 
늦은 해마다 10%씩 더 내셔야 합니다. 

이 추가 비용은 Part B를 사용하시는 동안 계속 납부하셔야 합니다.

예를 들어 (핸드북에는 없는 일반 정보): 
2년 늦게 가입하셨다면 정상 가격보다 20% 더 내시게 됩니다. 
정상 가격이 100달러라면 120달러를 내시는 것입니다.

💡 참고하세요: 중요한 결정을 하실 때는 Medicare 공식 기관
(1-800-MEDICARE)이나 전문가와 상담하시는 것이 좋습니다.
```

## 사용자 경험 개선

### 웰컴 메시지
- 더 친근하고 쉬운 한국어/영어
- "편하게 물어보세요" - 심리적 거리감 감소
- 핵심 기능 쉽게 설명

### 예시 질문
- 전문 용어 대신 일상 언어 사용
- "late enrollment penalty" → "늦게 가입하면"
- "enroll" → "신청"

### Disclaimer
- 딱딱한 법적 문구 제거
- 친근한 안내 문구로 변경
- 구체적 연락처 제공 (1-800-MEDICARE)

## 효과

1. **이해도 향상**: 60세 이상 어르신들이 쉽게 이해
2. **완성도 향상**: 메뉴얼에 없어도 도움이 되는 답변 제공
3. **신뢰도 유지**: 출처를 명확히 구분하여 투명성 확보
4. **접근성 향상**: 친근한 언어로 심리적 거리감 감소

## 주의사항

- 쉬운 언어 사용하되 정확도는 유지
- 일반 지식 사용 시 반드시 출처 명시
- 메뉴얼 정보를 항상 우선으로
- 복잡한 내용도 단계별로 쉽게 설명
